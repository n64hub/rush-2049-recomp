San Francisco Rush 2049: Recompiled v0.1.41: see-through scenery drawn farthest first, so a far sail no longer covers the lamp or boat in front of it.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.41-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.41-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** with See-Through Order on **Sorted** (the default), two see-through things in a line still covered each other in the order the game drew them, so at Track 1's start the farthest sail boat was drawn over the nearer boats and over the street lamp in front of them. The game draws many of these pictures at once (a whole row of lamps, then all the boats), so putting whole batches in order could not fix it. Sorted now draws see-through scenery one picture at a time, farthest first, so the nearer lamp, sail or tree is drawn over what is behind it. Your car's flame, the smoke and the ghosts' arrows are drawn as before.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
