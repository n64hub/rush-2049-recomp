San Francisco Rush 2049: Recompiled v0.1.35: see-through scenery, such as the tree by the sculpture on Track 1, no longer goes missing against what is behind it.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.35-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.35-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**See-through scenery in order:** trees, lamps, sails and glass are see-through pictures, and the game draws each one wherever it comes in its list, so a wall or road behind one that happened to be drawn after it painted over it. The tree in the planter by the sculpture on Track 1 was half see-through against the track behind it, though an N64 shows it the same way. See-through scenery is now drawn after the rest of the scene, so it shows over whatever solid is behind it. Two see-through things still cover each other as the game drew them, so a boat's sail at Track 1's start still covers the street lamp in front of it. Your car's flame and the smoke look as they did. The new **See-Through Order** setting on the Graphics tab is **Sorted** by default; **Original** draws it as the game shipped.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
