San Francisco Rush 2049: Recompiled v0.1.76: the Windows download no longer carries the debugging symbols or the folder the game was built in.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.76-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.76-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Changed:** the Windows download no longer includes `Rush2049Recompiled.pdb`, the debugging symbols, and the game no longer holds the folder it was built in. A crash's report in `rush2049.log` gives each place as the file and an offset into it, which the project can still name.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
