San Francisco Rush 2049: Recompiled v0.1.42: with Controllers on Per Player, the keyboard's keys can be seen and changed on the Controls tab again.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.42-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.42-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** with **Controllers** on **Per Player** (the default) and only the keyboard, the Controls tab showed four empty player cards, so the keyboard's keys couldn't be seen or changed until you assigned the keyboard to player 1, and then its profile showed every binding blank and **Reset to defaults** left it blank. Now, until a controller joins, the Controls tab shows the one-player bindings, with the keyboard's behind the keyboard button, as on **One Player**. A player given the keyboard with **Assign Players** starts from those keyboard keys, including a keyboard profile left blank by an earlier version, and **Reset to defaults** gives them the default keys (a second player on the same keyboard still starts empty, so the two don't share keys). Once a controller is player 1, player 1's **Edit Profile** has the same button to show the keyboard's keys that player 1 also plays with.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
