San Francisco Rush 2049: Recompiled v0.1.49: two players on the same kind of controller each have their own bindings, and a Nintendo Switch Online N64 controller no longer comes up with A and B swapped.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.49-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.49-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** with Controllers at Per Player, two players on the same kind of controller shared one set of bindings, so changing one player's on the Controls tab changed the other's too. The game keeps bindings per kind of controller, and two controllers of one kind look the same to it. Now a second player on the same kind of controller gets bindings of their own, starting from the first player's, and so do a third and a fourth; each player's Edit Profile changes only theirs.

**Fixed:** a Nintendo Switch Online N64 controller that doesn't answer the first thing SDL (the library the game reads controllers through) asks it when it connects shows up as "N64 Controller" instead of "Nintendo N64 Controller", and was then read like a Switch Pro controller, with A and B swapped, and two other buttons with each other too. It now reads the same as one that answered.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
