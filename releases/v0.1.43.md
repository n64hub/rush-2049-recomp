San Francisco Rush 2049: Recompiled v0.1.43: the keyboard's keys on the Controls tab come from the shared support for every recompiled game, and two players sharing the keyboard no longer get the same keys.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.43-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.43-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Changed:** v0.1.42's fix for the keyboard's keys on the Controls tab is now the one every recompiled game on the same support has: **Reset to defaults** gives the keyboard player their default keys, and a gamepad player 1, who also plays the keyboard until another player is given it, has the controller/keyboard switch on their **Edit** page. One thing differs: with two players on the keyboard (**Assign Players**, the keyboard given to a second player too), only the first gets the default keys on **Reset to defaults**. The second starts with none, so one key no longer moves both players.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
