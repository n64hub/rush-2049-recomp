San Francisco Rush 2049: Recompiled v0.1.65: Split-Screen Aspect Ratio has Full Window, so split screen fills a window wider than 16:9.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.65-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.65-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**New:** **Split-Screen Aspect Ratio** on the Graphics tab has a third value, **Full Window**: in a window wider than 16:9 (21:9, say), 2- and 4-player split screen reaches the window's edges with no bars at the sides, while a single player's HUD stays where **HUD Placement** puts it. Expand, the default, is unchanged. Contributed by @IZIDIOZZ (#346).

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
