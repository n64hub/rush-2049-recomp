San Francisco Rush 2049: Recompiled v0.1.32: the game's own Graphics options wait for Apply.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.32-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.32-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** on the Graphics tab, the game's own options (Game Frame Rate, Input Lag, Hi-res Font, Hi-res Title Screen, Draw Distance, Level of Detail, Scenery Culling, Split-Screen Aspect Ratio and Menu Aspect Ratio) took effect the moment you picked them, yet closing the menu still asked you to apply or discard them. They now wait for **Apply**, like Resolution and the other options on that tab: the menu stays open after Apply, so you see the change behind it at once, and closing with **Discard** leaves the game as it was.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
