San Francisco Rush 2049: Recompiled v0.1.75: the game closes with a message instead of freezing when its graphics device keeps being lost.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.75-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.75-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** when the graphics device is lost again soon after the game started over on a new one (a GPU that keeps hanging), the game no longer freezes on a picture that can't be closed: it says so in a message box and closes, suggesting a driver update or the other Graphics API. On Direct3D 12 a lost device is now replaced by a new Direct3D 12 device instead of the game falling back to Vulkan. This comes with the renderer every recomp of this project shares.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
