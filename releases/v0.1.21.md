San Francisco Rush 2049: Recompiled v0.1.21: Rewind no longer crashes in Stunt.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.21-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.21-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** holding **Rewind** in Stunt mode crashed the game within a few rewinds on the first arena. Rewind now winds back an animated piece of the arena with the rest of the race, so it plays on. A texture load in the renderer that skips rows no longer writes past texture memory, and Rewind and the hi-res font take less of each frame. Nothing to set: settings and saves are as before.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
