San Francisco Rush 2049: Recompiled v0.1.37: the ghosts' arrows in a Ghost Race show over far buildings again with See-Through Order on Sorted.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.37-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.37-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** in a Ghost Race, with See-Through Order on **Sorted** (the default since v0.1.35), a ghost's arrow far down the track could be hidden behind see-through buildings near the horizon. The game draws the arrows and the cars' effects after a few far see-through pieces of scenery, and Sorted moved those pieces to the very end, over the arrows. They now go right after the solid scenery, so everything the game drew after them, the arrows included, is drawn after them again.

Two see-through things in front of each other (a lamp and a sail, one tree against another) still cover each other as the game drew them. Drawing them far to near instead was tried and changed nothing you can see on Track 1, so it stays as the game drew it.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
