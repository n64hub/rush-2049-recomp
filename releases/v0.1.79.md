San Francisco Rush 2049: Recompiled v0.1.79: Controller Pak saves kept by the runtime every recomp of this project shares, and smoother frames between the game's own.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.79-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.79-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Changed:** Controller Pak saves are now kept by the runtime every recomp of this project shares, in place of the game's own copy of it. They are the same `saves/controllerpak_<port>.mpk` files: saves from earlier versions load as they did, a symlinked save stays a link, and **Controller Pak Size** and every **Controller Accessory** work as before. The frames drawn between the game's own are closer to it: a camera that keeps moving fast right after a cut gets them, a 2D bar or icon that grows, shrinks or is cut at the screen's edge moves smoothly, and a frame that runs late no longer flashes half drawn. 32 more controllers are recognised.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
