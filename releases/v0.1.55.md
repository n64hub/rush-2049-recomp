San Francisco Rush 2049: Recompiled v0.1.55: the game starts on a Windows PC with little memory to spare, and slow scrolling textures and some moving shapes glide smoothly between frames.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.55-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.55-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:**

- On Windows the game no longer stops at start with "Failed to allocate memory!" on a PC with little memory to spare: it now commits only the 512 MB of console memory it uses, not a much larger reserve.
- Slow scrolling textures move smoothly on every frame drawn, instead of in steps.
- Shapes the game moves itself, without a matrix ID, glide between frames like everything else instead of jumping at each game frame.
- A rare frame in which a far, small object could be drawn huge in front of everything is gone.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
